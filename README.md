Bienvenido a mi portafolio web. Este proyecto representa mi trabajo como desarrollador Frontend, donde podrás encontrar una muestra de mis proyectos, habilidades, información personal y formas de contacto.

## 📌 Descripción

Este portafolio fue creado con HTML, CSS y JavaScript. Está diseñado para ser **totalmente responsivo**, adaptándose a dispositivos móviles, tabletas y pantallas de escritorio. También incluye un menú hamburguesa que se activa en dispositivos móviles.

## ✨ Funcionalidades

- ✅ Secciones: Inicio, Proyectos, Sobre mí, Skills y Contacto.
- ✅ Navegación suave y anclada.
- ✅ Diseño adaptable (Responsive).
- ✅ Menú hamburguesa en pantallas pequeñas.
- ✅ Código organizado, limpio y escalable.

## 🧰 Tecnologías Utilizadas

- HTML5
- CSS3 (con Flexbox y Media Queries)
- JavaScript puro (sin frameworks)
- Icons de emojis y recursos web
